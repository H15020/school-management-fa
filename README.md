# مدیریت مدرسه فارسی | Persian School Management

اپلیکیشن اندرویدی مدیریت مدرسه با رویکرد آفلاین‌محور، رابط فارسی و پشتیبانی از Android 8.0 (API 26) و بالاتر.

## وضعیت نسخه ۰٫۳٫۰
- صفحه اصلی فارسی و راست‌چین
- پایگاه داده محلی Room
- داده آغازین مدرسه زاگرس و چهار کلاس سال ۱۴۰۵–۱۴۰۶
- ثبت، جست‌وجو، ویرایش و غیرفعال‌سازی پرونده دانش‌آموز
- فهرست کلاس‌های فعال
- بخش درباره برنامه و اطلاعات تماس توسعه‌دهنده
- درج نام توسعه‌دهنده در نوار ثابت همه صفحات

## سازگاری و کارکرد
- حداقل Android 8.0 / API 26
- Kotlin و Jetpack Compose
- Room 2.6.1
- بدون وابستگی اجباری به Google Play Services یا Firebase
- عملیات فعلی پایگاه داده به صورت محلی و بدون اینترنت انجام می‌شود.
- داده‌ها در حافظه داخلی برنامه باقی می‌مانند؛ حذف برنامه یا پاک‌کردن داده‌های آن می‌تواند اطلاعات را از بین ببرد. پشتیبان‌گیری و بازیابی هنوز در دست توسعه است.

## محدودیت‌های فعلی
ورود امن کاربران، نقش‌ها و مجوزهای اجرایی، مدیریت کلاس و کارکنان، حضور و غیاب، نمرات، کارنامه، رمزنگاری و پشتیبان‌گیری هنوز تکمیل نشده‌اند. این نسخه برای آزمون اولیه است و نباید بدون تکمیل کنترل دسترسی و پشتیبان‌گیری برای داده‌های حساس مدرسه به کار گرفته شود.
