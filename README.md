# مدیریت مدرسه فارسی | Persian School Management

اپلیکیشن اندرویدی مدیریت مدرسه با رویکرد **آفلاین‌محور**، رابط فارسی و پشتیبانی از مدارس مختلف.

## وضعیت پروژه
این مخزن در مرحله ساخت اسکلت اولیه اندروید است. نسخه فعلی یک نمونه آغازین رابط کاربری است و هنوز برای استفاده عملیاتی مدرسه آماده نیست.

## اصول طراحی
- فارسی و راست‌چین واقعی در رابط کاربری
- پشتیبانی از Android 8.0 (API 26) و بالاتر
- کارکرد اصلی بدون اینترنت و همگام‌سازی در زمان دسترسی
- پایگاه داده محلی Room و صف همگام‌سازی
- عدم وابستگی اجباری به Google Play Services، Firebase یا سرویس‌های تحریم‌پذیر
- جداسازی داده‌های مدرسه و سال تحصیلی از کد برنامه
- کنترل دسترسی مبتنی بر نقش، دامنه و بازه زمانی
- ثبت رویدادهای حساس و تهیه نسخه پشتیبان رمزگذاری‌شده

## فناوری‌های پایه
- Kotlin
- Jetpack Compose و Material 3
- Room (در مرحله پیاده‌سازی داده)
- WorkManager (برای همگام‌سازی پس از پیاده‌سازی شبکه)

## ساخت پروژه
پروژه با Android Gradle Plugin و Kotlin تعریف شده است. برای ساخت APK به Android Studio یا محیط ساخت سازگار با Gradle و Android SDK نیاز است.
