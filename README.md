# مدیریت مدرسه فارسی | Persian School Management

اپلیکیشن اندرویدی مدیریت مدرسه با رویکرد **آفلاین‌محور**، رابط فارسی و پشتیبانی از مدارس مختلف.

## وضعیت پروژه
نسخه ۰٫۲٫۰ شامل اسکلت اندروید، صفحه آغازین فارسی و مدل اولیه پایگاه داده محلی Room است. این نسخه هنوز برای استفاده عملیاتی مدرسه آماده نیست و ساخت/آزمایش APK آن باید انجام شود.

## اصول طراحی
- فارسی و راست‌چین واقعی در رابط کاربری
- پشتیبانی از Android 8.0 (API 26) و بالاتر
- کارکرد اصلی بدون اینترنت و همگام‌سازی در زمان دسترسی
- پایگاه داده محلی Room و صف همگام‌سازی آتی
- عدم وابستگی اجباری به Google Play Services یا Firebase
- جداسازی داده‌های مدرسه و سال تحصیلی از کد برنامه
- کنترل دسترسی مبتنی بر نقش، دامنه و بازه زمانی
- ثبت رویدادهای حساس و پشتیبان‌گیری رمزگذاری‌شده در مراحل بعد

## فناوری‌ها
- Kotlin و Jetpack Compose
- Room 2.6.1 برای پایگاه داده محلی
- Android Gradle Plugin 8.7.3 و Kotlin 2.0.21
