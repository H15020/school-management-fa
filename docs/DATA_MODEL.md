# مدل داده نسخه ۱

## اصول
- همه شناسه‌ها رشته‌های یکتا هستند تا همگام‌سازی آینده میان دستگاه‌ها ساده‌تر شود.
- تاریخ‌های روزانه به‌صورت Epoch Day و زمان رویدادها به‌صورت Unix milliseconds ذخیره می‌شوند؛ نمایش شمسی در لایه رابط انجام خواهد شد.
- هر مدرسه شناسه مستقل دارد و داده‌های سال تحصیلی به شناسه سال وابسته‌اند.
- حذف سوابق آموزشی با حذف آبشاری انجام نمی‌شود؛ ثبت‌نام و کلاس‌ها از حذف فیزیکی سوابق جلوگیری می‌کنند.
- اطلاعات نمونه مدرسه نباید به‌صورت ثابت در دیتابیس یا کد برنامه قرار گیرد.

## جدول‌های پایه
| جدول | کاربرد |
|---|---|
| schools | مشخصات هر مدرسه |
| academic_years | سال‌های تحصیلی مستقل و قابل بایگانی |
| users | حساب‌های کاربری و نقش |
| staff | کارکنان مدرسه |
| students | پرونده دانش‌آموز |
| school_classes | کلاس هر پایه در یک سال |
| subjects | دروس |
| enrollments | ثبت‌نام دانش‌آموز در کلاس و سال |
| teacher_assignments | تخصیص دبیر به کلاس و درس |
| access_grants | مجوز محدود و زمان‌دار |
| audit_logs | سابقه عملیات حساس |

## نکات امنیتی
- فیلدهای passwordHash و passwordSalt باید فقط با الگوریتم مشتق‌سازی رمز مقاوم تولید شوند؛ رمز خام هرگز ذخیره نمی‌شود.
- نسخه فعلی هنوز ورود کاربر و رمزنگاری داده‌های حساس را پیاده‌سازی نکرده است.
- پیش از استفاده واقعی باید رمزنگاری پشتیبان، مدیریت کلید و آزمون دسترسی اضافه شود.
